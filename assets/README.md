# Images

Drop your images here with these exact filenames — the README already links to
them.

| File | Where it appears | Suggested size |
|---|---|---|
| `banner.png` | Top of the README, above the title | 1440 × 400 (displays at 720 wide) |
| `how-it-works.png` | The "How it works" section | 1640 wide (displays at 820) |

Notes:

- **Use 2× the display width.** GitHub serves these on high-DPI screens, and a
  1:1 image looks soft.
- **A transparent background will not work in both themes.** GitHub renders READMEs
  on white *and* dark backgrounds, so mid-grey text on transparency becomes
  unreadable in one of them. Either bake in a solid background, or keep contrast
  high enough to survive both.
- PNG for diagrams and screenshots; SVG is fine too if you update the `<img src>`
  in the README.

Until you add them the README will show broken-image placeholders — that is
expected, and everything else renders normally.
